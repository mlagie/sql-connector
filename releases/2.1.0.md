# Release v2.1.0

## Feature

- Added schema-driven TypeScript inference so model properties can be derived automatically from `Schema` definitions.
- Introduced `InferSchema` and generic model typings so `find()`, `count()`, and `customRequest()` return properly typed results without manual interfaces.
- Added support for SQL-to-TypeScript type mapping, including nullable, required, and default-based field inference.

## Fix

- Exposed the package declaration resolution more explicitly so TypeScript can reliably find `@mlagie/sql-connector` types in consuming projects.
- Kept the runtime `Schema` shape compatible with the new typing model.

## Impact

TypeScript users can now create models directly from a schema and get automatic property completion and compile-time errors for invalid fields, with no need to define a separate interface by hand.
