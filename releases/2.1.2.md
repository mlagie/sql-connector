# Release v2.1.2

## Fix

- Fixed `NormalizeSqlType` generic resolution order so constructor-based schema types (`Number`, `Boolean`, `Date`, etc.) are inferred correctly instead of degrading to `string`.
- Fixed schema nullability inference for fields declared with `default: null`, which now resolve to nullable TypeScript types (for example `Date | null`).
- Improved compatibility with `exactOptionalPropertyTypes: true` by allowing nullable defaults to be passed as `null` without conditional object spreading.

## Impact

TypeScript users now get correct compile-time types for constructor-based schema fields and can pass nullable values in a predictable way when using strict optional property settings.
