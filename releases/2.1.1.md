# Release v2.1.1

## Fix

- Improved foreign key cycle detection to report the full dependency path instead of a generic error message.
- Added support for `Now` as a valid temporal default value when generating `CREATE TABLE` statements.
- Normalized `Now` to `CURRENT_TIMESTAMP` for date and datetime fields so table creation no longer fails with an invalid default error.

## Impact

Debugging schema issues is now easier because the error message shows which tables form the cycle, and models can safely use `default: "Now"` for timestamp-style fields.
