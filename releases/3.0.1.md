# Release 3.0.1

## Fixed

**Dynamic Table Names in Delete Query**: Fixed an issue where the `delete` function did not properly handle dynamic table names specific to PostgreSQL requirements.

## Changed

**Unified Delete Functionality**: Merged `deleteOne` into the main `delete` function. The `delete` function now handles both bulk and single-row deletions seamlessly.

## Removed

**deleteOne Function**: Removed the redundant `deleteOne` function.

## Migration Note

If you were previously using `deleteOne()`, simply replace it with `delete()` without passing any filtering parameters to achieve the exact same behavior.
