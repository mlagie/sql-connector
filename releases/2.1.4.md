# Release v2.1.4

This release fixes the TypeScript typing for `select` in `find()` queries.

- Added proper support for advanced select objects such as `{ count: 'id', as: 'total' }`
- Allowed mixed selections combining plain fields and aggregation expressions
- Improved compatibility with SQL queries using grouped or aggregated output

This resolves the typing error where the selector array was incorrectly restricted to `string[]` only.
